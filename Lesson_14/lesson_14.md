### 追いかけロボットと回避ロボットの違いを考えよう

レッスン13のロボットは**物体が近づくと追いかける**動作をしていたね。

今回は**同じハードウェア**を使って**逃げるロボット**を作るよ。

センサーの値に対してどんな動作をするか、2つを比べてみよう：

| 右センサー | 左センサー | 追いかけロボット | 回避ロボット |
|---|---|---|---|
| 検出（LOW） | 検出（LOW） | 後退（近づきすぎ） | 後退（前に障害物） |
| 未検出（HIGH） | 未検出（HIGH） | 停止（何もない） | **前進**（何もない） |
| 検出（LOW） | 未検出（HIGH） | 右に向ける | **左に回避** |
| 未検出（HIGH） | 検出（LOW） | 左に向ける | **右に回避** |

「追いかける」→「逃げる」では**センサーが何もないとき前進し、障害物があった方向から遠ざかる**点が違うね！

### ミッションチャレンジ

#### サンプルコードを動かそう

```C++
#include "motor_driver.h"  // 標準モーター制御ライブラリ

#define BUZZ_PIN             13  // ブザー → D13
#define RightObstacleSensor   2  // 右障害物センサー → D2
#define LeftObstacleSensor   A5  // 左障害物センサー → A5

#define SPEED  180  // モーター速度（0〜255）

// 回避ロジック：センサー値に応じて障害物から逃げる
void auto_avoidance() {
  int rightSensor = digitalRead(RightObstacleSensor);  // LOW=物体あり
  int leftSensor  = digitalRead(LeftObstacleSensor);   // LOW=物体あり

  if (rightSensor == LOW && leftSensor == LOW) {
    // 両センサーが検出 → 前方に障害物！後退して回避
    digitalWrite(BUZZ_PIN, LOW);  delay(200);  // 警告音
    digitalWrite(BUZZ_PIN, HIGH);
    go_Back(SPEED, 300);
  }
  else if (rightSensor == HIGH && leftSensor == HIGH) {
    // 何もない → 前進してどんどん進む
    go_Advance(SPEED);
  }
  else if (rightSensor == LOW && leftSensor == HIGH) {
    // 右に障害物 → 左に回避
    go_Left(SPEED);
  }
  else if (rightSensor == HIGH && leftSensor == LOW) {
    // 左に障害物 → 右に回避
    go_Right(SPEED);
  }
}

void setup() {
  init_GPIO();
  pinMode(BUZZ_PIN, OUTPUT);
  digitalWrite(BUZZ_PIN, HIGH);

  pinMode(RightObstacleSensor, INPUT);
  pinMode(LeftObstacleSensor, INPUT);

  Serial.begin(9600);
}

void loop() {
  auto_avoidance();
}
```

#### センサーの感度を調整しよう

障害物センサーの裏側についている青いつまみ（ポテンショメーター）を小さいドライバーで回すと感度が変わるよ。

- 時計回り → 検出距離が短くなる（近くまで来ないと反応しない）
- 反時計回り → 検出距離が長くなる（遠くからでも反応する）

コース内で障害物を置いて、うまく回避できるよう感度を調整してみよう。
