# レッスン27 オリジナルロボットを作ろう(3)〜組み立て
## 部品をアクリル板に取り付けよう

### このレッスンで身につける力

- [ ] モーター・モータードライバー・Arduinoをアクリル板に固定できる
- [ ] センサー類を正しい向きに配置・配線できる
- [ ] ケーブルをタイラップ（結束バンド）で整理できる
- [ ] 組み立て後に配線の確認ができる

---

### ミッションの準備

#### 0. 必要な道具・材料

- [ ] 加工済みアクリル板（L26で作ったもの）
- [ ] ギアモーター x4
- [ ] モータードライバー x1
- [ ] Arduino UNO x1
- [ ] バッテリーボックス x1
- [ ] 各種センサー（自分が選んだもの）
- [ ] M3ネジ・ナット・スペーサー 各種
- [ ] ドライバー・ペンチ
- [ ] タイラップ（結束バンド）

---

### ミッションチャレンジ

#### ミッション1：モーターを取り付けよう

1. 4つのギアモーターをアクリル板の所定の位置に合わせる
2. モーター用ホルダーとネジで固定する
3. 取り付け方向（前後）を確認する

> **確認ポイント**：左右のモーターが正しい向きになっているか、前進したときに全部のホイールが前に進むことを確認しよう。

- [ ] 4つのモーターが正しい向きで固定できたらチェック！

---

#### ミッション2：電子部品を取り付けよう

1. **モータードライバー**をアクリル板にM3プラスチックスペーサーで固定
2. **Arduino UNO**を固定
3. **バッテリーボックス**を固定

> モータードライバーとArduinoを重ねて取り付けることもできるよ（スタック構成）。

- [ ] 電子部品が固定できたらチェック！

---

#### ミッション3：センサー類を取り付けよう

自分が選んだセンサーを、動作に合った向きに取り付けよう。

| センサー | 推奨取り付け位置 |
|---|---|
| 障害物センサー（x2） | 前方左右（ロボット正面） |
| 超音波センサー | 前方中央（首振りサーボに乗せる場合も） |
| ライントラッキングセンサー | 底面中央 |
| ブザー | 上面（音が聞こえる場所） |

- [ ] 選んだセンサーが正しい向きで固定できたらチェック！

---

#### ミッション4：配線してケーブルを整理しよう

1. モーター → モータードライバー を接続
2. センサー → Arduino を接続（ピン番号は motor_driver.h のピン配置表を参照）
3. 電源（バッテリーボックス）を接続
4. 余ったケーブルをタイラップで束ねて整理

> **配線確認チェックリスト**：
> - モーターのプラスとマイナスが逆になっていないか
> - センサーの VCC・GND・SIG の向きが正しいか

- [ ] 配線が完成してケーブルが整理できたらチェック！

---

### まとめ

- 組み立て順：**モーター → 電子部品 → センサー → 配線**
- 配線後は必ず**VCC・GND・SIG の確認**をすること
- ケーブルは**タイラップで整理**すると断線防止になる
