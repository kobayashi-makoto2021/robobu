### ミッションチャレンジ

#### ミッション1：最終調整をしよう

L30で作った必殺技コードを見直して、最後の調整をしよう。

**調整のポイント**：

```cpp
// スピードを状況に応じて調整する例
#define ATTACK_SPEED  220   // 攻撃時のスピード
#define PATROL_SPEED  180   // 通常移動のスピード
#define EVADE_SPEED   200   // 回避時のスピード

// タイミングを微調整する例
go_Advance(ATTACK_SPEED, 800);   // 時間（ms）を変えて距離を調整
go_Left(EVADE_SPEED, 350);       // 角度を調整
```

- [ ] コードの最終調整ができたらチェック！

---

#### ミッション2：練習対戦で確認しよう

大会前に練習対戦を行い、動作を確認しよう。

**練習対戦で確認すること**：
- ロボットが意図した通りに動くか
- センサーが正しく反応しているか
- バッテリーが持続するか

> うまくいかない部分があれば音デバッグ（L08）を使って原因を調べよう。

- [ ] 練習対戦で動作確認ができたらチェック！

#### ミッション3：決勝大会！

### コース全体を振り返ろう

このコースで学んだことを整理しよう。

| レッスン | 内容 |
|---|---|
| L00〜L05 | Arduinoの基礎・ロボットの組み立て |
| L06〜L10 | モーター制御・センサー基礎 |
| L11〜L15 | 自律動作（迷路・障害物回避） |
| L16〜L18 | ライントレース・サーボ・超音波 |
| L19〜L24 | プログラミング応用・WiFi・Bluetooth |
| L25〜L28 | オリジナルロボット製作 |
| L29〜L31 | ロボット対戦ゲーム |

> **これだけの技術を身につけた！** モーター制御、センサー、WiFi/Bluetooth通信、自律動作プログラム、そしてオリジナルロボット製作まで、本物のロボットエンジニアと同じことができるようになったよ。
