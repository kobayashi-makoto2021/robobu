## フォルダの命名規則

```
<通し番号>_<レッスンタイトル>_<段階>/
├── レッスン_<通し番号>.md    生徒向けテキスト
├── image/                    画像
│   └── xcf/                  GIMP等の編集元ファイル
└── sample/                   サンプルコード（<名前>/<名前>.ino）
```

通し番号は入門・実践を通して 01〜21。段階をフォルダ名に含めるため、段階ごとのフォルダは作らない。

## レッスンテキストの構成

各 `レッスン_NN.md` は方針書 §5 の形式で雛形を置いてある。

```
ミッション → このレッスンで身につける力 → 今回使う技術
→ ミッションの準備 → メインミッション → 確認 → やってみよう → まとめ
```

「確認」「やってみよう」「まとめ」は現行教材に無い、または任意扱いになっている工程。
必ず埋めること（→ 設計書 §7）。

### まとめの運用

|項目|内容|
|---|---|
|書く場所|Googleサイトの生徒ごとの**まとめページ**|
|書く頻度|**1日1回**。複数レッスンを進めた日も、1レッスンが1回で終わらなかった日も1回|
|必ず書くもの|やったこと／わかったこと／感じたこと／つぎやること の**4つすべて**|
|必ず入れるもの|**スクリーンショットか画像を1枚以上**|

頻度がレッスン単位ではなく1日単位のため、**そのレッスンで何ができるようになったかのチェックリストは各レッスンのテキスト側に置く**。
生徒はそれを見ながら、まとめページに4項目を書く。

### サンプルコードの置き方

```
<レッスン>/sample/<スケッチ名>/
├── <スケッチ名>.ino
└── motor_driver.h      ← common/ からの複製（ロボットレッスンのみ）
```

Arduino IDE はスケッチと同じフォルダの `.h` しか読まないため、各スケッチフォルダに複製を置いている。
正本は `common/motor_driver.h`。変更したときの配りなおし方は `common/README.md` を参照。

### 実機で確認が必要なこと

| 項目 | 内容 |
|---|---|
| **ENA のピン** | 11〜13・15〜19 は **D3**、赤外線を使う **14・20・21 は D9**（IRremoteがTimer2を使い、D3のPWMと両立しないため）。配線を変えて動作確認すること |
| **左右の向き** | 旧L14のコメントでは 7・8 が「右」だったが、他レッスンでは「左」。`motor_driver.h` は **12・11＝右 / 7・8＝左**で統一。実機で確認 |
| ブザー極性 | 個体によって VCC/GND が逆のものがある（旧L11の注記） |
| **20・21 の旋回** | 旧コードは「片輪を止めて回る」動き。20・21 は `motor_driver.h` の「その場で回る」動きに変えた（レッスン13の90度計測をそのまま使えるようにするため）。18・19 は旧の動きのまま残してある |
| **19 の操舵** | 旧コードの `if (cs.angle = 1)` が代入になっていたため `==` に直した。ハンドルの効き方が変わるので確認すること |
| **IRコード** | IRremote v4 に移行し、`0xFF18E7`（8けた）から `command` の `0x18`（2けた）に変えた。実際にこの値が出るか確認すること |
| **20・21 の弾** | Sony 12ビットの `0xAAA`/`0xBBB` から NEC の `0xAA`/`0xBB` に変更。撃てるか・当たったら倒れるかを確認すること |
| **18 のWiFiライブラリ** | WiFiEsp のままか WiFiEspAT に乗り換えるかは**実機で判断する**。手順は [検証_WiFiライブラリ.md](18_Wifi接続でロボットを動かそう_実践/検証_WiFiライブラリ.md) |
