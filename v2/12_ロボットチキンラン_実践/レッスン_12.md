## メインミッション

### ステップ1 ロボットをまっすぐ進ませよう

ロボットをまっすぐ進ませるには **`go_Advance` 関数**を使うよ。

```C++
go_Advance(スピード, 止まるまでの時間);
```

と書くと、指定された時間がたつまで前に進み続けます。

試しに `//ここから下にプログラムを書く` の下に、こう書いて動かしてみよう。

```C++
  go_Advance(100, 1000);
  stop_Stop();
```

プログラムを実行すると、ロボットが1秒間（1000ミリ秒間）進みます。

- [ ] ロボットの前進ができたらチェック！

### ステップ2 進む距離を予想しよう

いきなりギリギリをねらうと、たいてい行きすぎます。**先に計算で予想してから試そう。**

#### 距離の計算

```
進む距離 = 速さ × 時間
```

レッスン11で作った表を見てみよう。例えば「速さ150で1秒なら30cm進む」と分かっていれば、

- 60cm進みたい → 1秒で30cmだから、**2秒**
- 45cm進みたい → **1.5秒 ＝ 1500ミリ秒**

と予想できますね。

#### 記録しよう

コースのスタートからゴールまでの距離を測って、ノートに書こう。

| 項目 | 数字 |
|---|---|
| スタートからゴールまでの距離 | cm |
| 使う速さ | |
| 予想した時間 | ミリ秒 |
| 実際に進んだ距離 | cm |
| ずれ | cm |

### ステップ3 線ギリギリをねらおう

予想した時間で走らせて、どれくらいずれたか測ろう。そして**時間を少しずつ直していきます。**

| 回 | 時間 | 結果 | つぎどうする |
|---|---|---|---|
| 1回目 | ミリ秒 | 手前 / ちょうど / 行きすぎ | |
| 2回目 | ミリ秒 | | |
| 3回目 | ミリ秒 | | |

> **一気に変えないこと。** 500ミリ秒ずつ変えると行ったり来たりします。
> 100ミリ秒 → 50ミリ秒 → 20ミリ秒と、**だんだん細かく**していくのがコツです。

- [ ] 速度を調節できたらチェック！
- [ ] ラインギリギリで止まれたらチェック！

### ステップ4 ロボットを後ろに下がらせよう

ゴールの線ギリギリに止まったロボットを、今度はスタート地点まで戻してみよう。

ロボットを後ろに下がらせるためには **`go_Back` 関数**を使うよ。

```C++
go_Back(スピード, 止まるまでの時間);
```

試しにこう書いて動かしてみよう。

```C++
  go_Back(100, 1000);
  stop_Stop();
```

これができたら、速度と時間を変えて、コースのスタートの線ギリギリまで戻ってみよう！

- [ ] ロボットの後進ができたらチェック！
- [ ] スタートのラインギリギリで止まれたらチェック！

## 確認

### チキンランのルール

1. スタートの線から出発する
2. ゴールの線の**手前**で止まる（線をふんだら失格）
3. ゴールで止まったら、スタートの線の**手前**まで下がる（線をふんだら失格）
4. **線に近いほど勝ち**

### 確かめよう

- [ ] 行きも帰りも線をふまずに止まれた
- [ ] 線までのすき間を測った（行き： cm ／ 帰り： cm）
- [ ] **3回やって3回とも成功した**

3回続けて成功したら、まぐれではなく「できた」と言えます。

うまくいかないときは、ここを見てみよう。

| 症状 | 見るところ |
|---|---|
| まっすぐ進まない | タイヤのネジのしめ具合（レッスン10）／床のざらざら具合 |
| 毎回止まる場所がちがう | 電池が減っていないか。電圧計を見よう |
| だんだん短くなる | 電池が弱ってきている。同じプログラムでも距離は変わります |
| 進みすぎる | `delay` の時間を減らす。減らす量を半分ずつにしていく |

> **電池が減ると同じプログラムでも進む距離が変わります。** これは大事な発見です。

### 2. 止まる直前でブザーを鳴らそう

ゴールの手前で「ピッ」と鳴らしてから止まるようにしてみよう。

```C++
  go_Advance(150, 1500);
  beep(1, 100);        // 止まる合図
  stop_Stop();
```

### 3. だんだんおそくして止まろう（発展）

いまは全速力からいきなり止まっています。本物の車のように、**だんだんおそくして止まる**ようにしてみよう。

> ヒント：**レッスン04の `for` 文**を使って、速さを少しずつ下げていきます。

```C++
  for (int s = 200; s > 0; s = s - 20) {
    go_Advance(s, 100);
  }
  stop_Stop();
```

だんだんおそくすると、**止まる場所が正確になる**かな？試してくらべてみよう。

- [ ] だんだんおそくして止まれたらチェック

- 直すときは**だんだん細かく**（100 → 50 → 20 ミリ秒）
- **電池が減ると進む距離が変わる**
