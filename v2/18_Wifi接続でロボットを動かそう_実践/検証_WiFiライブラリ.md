# 【検証用】レッスン18 WiFiライブラリをどうするか決める

> **これは生徒用のテキストではありません。** 指導員が実機で確かめて、方針を決めるための手順書です。
> 決まったら結果を `v2/開発日誌.md` に残し、本編の `レッスン_18.md` を書きかえます。

## なぜ検証するのか

レッスン18で使っている **WiFiEsp** には、2つの問題があります。

| 問題 | 中身 |
|---|---|
| 配布が osoyoo の zip | `https://osoyoo.com/driver/WiFiEsp-master.zip` を落として入れる手順。リンクが切れたらレッスンが止まる。中身も配布時点で固定されたまま |
| ライブラリ自体が古い | WiFiEsp は **2019年で更新が止まっています** |

後継として **WiFiEspAT** があり、こちらは現在も保守されています。
ただし WiFiEspAT は **ESP8266側のATファームウェアが 1.7 以降**でないと動きません。
教室のシールドがどのバージョンかは、**実機で見ないと分かりません。**

だから、次の順番で確かめます。

```
検証1  ATファームウェアのバージョンを見る   ← ここで結論がほぼ決まる
  ↓
検証2  WiFiEsp（ライブラリマネージャ版）で動くか
  ↓
検証3  WiFiEspAT で動くか
  ↓
判断
```

## 検証1 ATファームウェアのバージョンを見る

**ここが一番大事です。** この結果で、乗り換えられるかどうかがほぼ決まります。

1. `検証/at_version_check/at_version_check.ino` を書き込む
2. シリアルモニタを開く
3. **右下の改行設定を「CRおよびLF」にする**（ここを忘れると何も返ってきません）
4. 入力らんに `AT` と打って Enter

`OK` が返ってきたら、シールドと話せています。

> **何も返ってこない／文字化けするとき**
> スケッチの `#define ESP_BAUD 9600` を `115200` に書きかえて、もう一度書き込む。
> それでもダメなら、ジャンパーキャップの位置と配線（D4・D5）を見直す。

5. 続けて `AT+GMR` と打って Enter

こんな表示が出ます。

```
AT version:1.3.0.0(Jul 14 2016 18:54:01)
SDK version:2.0.0(656edbf)
compile time:Jul 19 2016 18:44:44
OK
```

**1行目の `AT version:` の数字を記録してください。**

### 記録らん

| 項目 | 結果 |
|---|---|
| ESP側のボーレート | 9600 / 115200 / どちらでもダメ |
| `AT` への応答 | OK / 応答なし / 文字化け |
| **AT version** | |
| SDK version | |

### この時点での見通し

| AT version | 意味 |
|---|---|
| **1.7 より古い**（1.3 など） | WiFiEspAT は**そのままでは動かない**。乗り換えるならファームウェア書き換えが全台に必要 |
| **1.7 以上 / 2.x** | WiFiEspAT に乗り換えられる可能性が高い。検証3へ進む価値がある |

> **参考：** いまのレッスン18のスケッチは `AT+CIOBAUD` というコマンドを使っています。
> これは**古いATファームウェア向けのコマンド**で、新しいものでは `AT+UART_CUR` に置きかわっています。
> つまり、教室のシールドは**古い側である可能性が高い**と予想しています。検証1で確かめてください。

## 検証2 WiFiEsp（ライブラリマネージャ版）で動くか

「ライブラリ自体は変えず、**入手方法だけ** osoyoo の zip からライブラリマネージャに変える」案が成り立つかを見ます。

1. **osoyoo の zip 版が入っていたら、先に削除する**
   - スケッチブックの `libraries` フォルダから `WiFiEsp-master` を消す
   - （Arduino IDE のメニューからは消せないので、フォルダを直接削除します）
2. ライブラリマネージャで **`WiFiEsp`** を検索してインストール（作者 bportaluri、2.2.2）
3. `検証/wifiesp_connect_test/wifiesp_connect_test.ino` を開く
4. `ssid[]` と `pass[]` を教室のWiFiに書きかえる
5. 書き込んで、シリアルモニタを見る

### 記録らん

| 項目 | 結果 |
|---|---|
| コンパイルが通ったか | 通った / エラー（内容： ） |
| `You're connected to the network` が出たか | 出た / 出ない |
| `IP Address:` が出たか | 出た（　　.　　.　　.　　） / 出ない |
| 本編のスケッチ（`sample/lesson_18_sample`）も動いたか | 動いた / 動かない |

> **本編のスケッチでも必ず確かめてください。** 接続だけできても、UDPで操縦できなければ意味がありません。
> アプリから前進・後進まで試すこと。

## 検証3 WiFiEspAT で動くか

**検証1のATバージョンが 1.7 より古かった場合、ここは失敗して当然です。**
「やってみたが、やはりダメだった」という記録を残す意味はあるので、時間があれば実施してください。

1. ライブラリマネージャで **`WiFiEspAT`** を検索してインストール（作者 JAndrassy）
2. **先に** `ファイル > スケッチ例 > WiFiEspAT > Tools > SetupWiFiConnection` を実行し、
   SSIDとパスワードをESP側に覚えさせる
   - WiFiEspAT は「ESPに保存された接続設定」を使う作りで、ここを飛ばすとつながりません
3. `検証/wifiespat_connect_test/wifiespat_connect_test.ino` を書き込む
4. シリアルモニタを見る

### 記録らん

| 項目 | 結果 |
|---|---|
| コンパイルが通ったか | 通った / エラー（内容： ） |
| `ESPモジュールを見つけました` が出たか | 出た / 出ない |
| `IP Address:` が出たか | 出た / 出ない（status= 　　） |

## 判断のしかた

検証の結果を、この表に当てはめてください。

| 検証1（ATバージョン） | 検証2（WiFiEsp） | 検証3（WiFiEspAT） | 結論 |
|---|---|---|---|
| 1.7より古い | 動く | 動かない | **WiFiEsp のまま。入手先だけライブラリマネージャに変える** |
| 1.7以上 | 動く | 動く | **WiFiEspAT に乗り換える**。保守されている側を選ぶ |
| 1.7以上 | 動かない | 動く | **WiFiEspAT に乗り換える** |
| どれでも | 動かない | 動かない | osoyoo の zip 版のまま据え置き。リンク切れに備えて**zipをリポジトリに置く** |

### 据え置くと決めた場合にやること
