# 【検証用】レッスン18 WiFiライブラリの入手先を切りかえる

> **これは生徒用のテキストではありません。** 指導員が実機で確かめるための手順書です。
> 終わったら結果を `v2/開発日誌.md` に残してください。

## 決まっていること

**WiFiEsp を使い続けます。** 後継の WiFiEspAT には乗り換えません。

| | |
|---|---|
| 理由 | WiFiEspAT は ESP8266 の**ATファームウェア 1.7 以降**を要求する。古い場合は書き換えが必要になるが、**キットは生徒が購入した持ち物**なので、こちらの都合で書き換えることはできない |
| 決定日 | 2026-09-25 |

## 何を変えるのか

**ライブラリの入手先だけ**を変えます。ライブラリもスケッチも配線も、そのままです。

| | 旧 | 新 |
|---|---|---|
| 入手先 | `https://osoyoo.com/driver/WiFiEsp-master.zip` | **ライブラリマネージャ**の WiFiEsp（作者 bportaluri） |
| 手順 | zipをダウンロード → ZIP形式のライブラリをインストール | 検索して「インストール」を押すだけ |

**なぜ変えるのか**

- 外部サイトのリンクに依存している。**リンクが切れたらレッスンが止まる**
- zipは配布時点で中身が固定されたまま。ライブラリマネージャなら修正版が入る
- 入門05でもライブラリマネージャを使うようにしたので、**手順を揃えられる**

## 確かめること

やることは1つだけです。**ライブラリマネージャ版に入れ替えても、今までどおり動くか。**

あわせて、生徒ごとにちがう可能性がある**ATファームウェアのバージョン**を記録しておきます。

---

## 手順1 いまのバージョンを記録する（任意だが推奨）

生徒のキットは購入時期によって中身がちがう可能性があります。
教室にある実機のバージョンを控えておくと、あとで「動かない」相談が来たときの手がかりになります。

1. 配線をレッスン18の本編と同じ状態にする（赤いジャンパーキャップの位置に注意）
2. `検証/at_version_check/at_version_check.ino` を書き込む
3. シリアルモニタを開き、**右下の改行設定を「CRおよびLF」にする**
4. `AT` と打って Enter → `OK` が返れば通信できている
5. `AT+GMR` と打って Enter

```
AT version:1.3.0.0(Jul 14 2016 18:54:01)
SDK version:2.0.0(656edbf)
OK
```

> **このスケッチは検証が終わっても消さないでください。**
> 「WiFiにつながらない」ときに、シールドと話せているかどうかを切り分ける道具として使えます。

## 手順2 ライブラリマネージャ版で動くか確かめる

1. **osoyoo の zip 版が入っていたら、先に削除する**
   - スケッチブックの `libraries` フォルダから `WiFiEsp-master` を消す
   - Arduino IDE のメニューからは消せないので、フォルダを直接削除します
   - **2つ入ったままだとどちらが使われるか分かりません。必ず消すこと**
2. ライブラリマネージャで **`WiFiEsp`** を検索してインストール（作者 bportaluri）
3. `検証/wifiesp_connect_test/wifiesp_connect_test.ino` を開く
4. `ssid[]` と `pass[]` を教室のWiFiに書きかえる
5. 書き込んで、シリアルモニタを見る

`IP Address:` が出れば接続成功です。

6. **本編のスケッチでも確かめる**
   `sample/lesson_18_sample/lesson_18_sample.ino` を書き込み、アプリから前進・後進まで試す

> **接続だけできても不十分です。** UDPで操縦できて初めて、レッスンとして成立します。
