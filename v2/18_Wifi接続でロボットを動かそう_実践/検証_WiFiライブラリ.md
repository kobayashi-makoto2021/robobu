### 1. WiFiEsp を使い続ける（WiFiEspAT には乗り換えない）

| | |
|---|---|
| 理由 | WiFiEspAT は ESP8266 の**ATファームウェア 1.7 以降**を要求する。古い場合は書き換えが必要になるが、**キットは生徒が購入した持ち物**なので、こちらの都合で書き換えることはできない |
| 決定日 | 2026-09-25 |

さらに、買ってもらっている以上**生徒ごとにATファームウェアのバージョンがちがう可能性**がある。
購入時期で osoyoo の在庫が変われば混在する。
教材は**一番古いものでも動く側**に寄せる必要がある。

## 確認しておきたいこと

### A. リポジトリのzipでインストールできるか（要実施）

リンクを差し替えたので、**実際にその経路で入れて動くか**は一度確かめること。

1. すでに WiFiEsp が入っていたら、スケッチブックの `libraries` から `WiFiEsp-master` を削除する
   - Arduino IDE のメニューからは消せないので、フォルダを直接削除します
   - **2つ入ったままだとどちらが使われるか分かりません**
2. `レッスン_18.md` のリンクから zip をダウンロード
3. スケッチ→ライブラリをインクルード→ZIP形式のライブラリをインストール
4. `検証/wifiesp_connect_test/wifiesp_connect_test.ino` を開き、`ssid[]` と `pass[]` を書きかえて実行
5. `IP Address:` が出れば成功
6. **本編の `sample/lesson_18_sample/lesson_18_sample.ino` でも確かめる**
   アプリから前進・後進まで試すこと。接続できても操縦できなければ意味がない

| 項目 | 結果 |
|---|---|
| zipからインストールできたか | できた / エラー（内容： ） |
| `IP Address:` が出たか | 出た（　　.　　.　　.　　） / 出ない |
| 本編スケッチでアプリから操縦できたか | できた / できない |

### B. 教室の実機のATバージョン（任意・推奨）

生徒のキットは購入時期によって中身がちがう可能性がある。控えておくと、
あとで「動かない」相談が来たときの手がかりになる。

1. 配線をレッスン18の本編と同じ状態にする（赤いジャンパーキャップの位置に注意）
2. `検証/at_version_check/at_version_check.ino` を書き込む
3. シリアルモニタを開き、**右下の改行設定を「CRおよびLF」にする**
4. `AT` と打って Enter → `OK` が返れば通信できている
5. `AT+GMR` と打って Enter

```
AT version:1.3.0.0(Jul 14 2016 18:54:01)
SDK version:2.0.0(656edbf)
OK
```

| 実機 | ESP側のボーレート | AT version |
|---|---|---|
| 1台目 | 9600 / 115200 | |
| 2台目 | 9600 / 115200 | |
| 3台目 | 9600 / 115200 | |

> **このスケッチは検証が終わっても消さないでください。**
> 「WiFiにつながらない」ときに、`AT` に `OK` が返るかどうかで
> **シールドと話せているか／その先が原因か**を切り分けられます。
