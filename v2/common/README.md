# 共通ファイル

全レッスンから参照する共通の資料・コードを置く。

| ファイル | 内容 | 状態 |
|---|---|---|
| `motor_driver.h` | モーター制御の共通ライブラリ。実践10で導入し、以降すべてのロボットレッスンで `#include` する | **未作成** |
| `センサーとピンの早見表.md` | 入門・実践で使った部品のピン配置一覧。応用で自作機体に載せ替えるときに参照する | **未作成** |
| `制作記録フォーマット.md` | 応用・発展で制作過程を残すための書式（経験項目#75） | **未作成** |

`motor_driver.h` は全ロボットレッスンのコードに影響するため、個別レッスンの改訂より先に確定させること。
詳細は `../ロボ部カリキュラム設計.md` §8 を参照。
