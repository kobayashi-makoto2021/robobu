# 共通ファイル

全レッスンから参照する共通の資料・コードを置く。

| ファイル | 内容 | 状態 |
|---|---|---|
| `motor_driver.h` | モーター制御の共通ライブラリ。実践11で導入し、以降すべてのロボットレッスンで `#include` する | **作成済み** |
| `センサーとピンの早見表.md` | 入門・実践で使った部品のピン配置一覧。応用で自作機体に載せ替えるときに参照する | **未作成** |
| `制作記録フォーマット.md` | 応用・発展で制作過程を残すための書式（経験項目#75） | **未作成** |

`motor_driver.h` は全ロボットレッスンのコードに影響するため、個別レッスンの改訂より先に確定させること。
詳細は `../ロボ部カリキュラム設計.md` §8 を参照。

## motor_driver.h の複製について

Arduino IDE は、**スケッチと同じフォルダにある** `.h` しか読み込めない。
そのため各レッスンの `sample/<スケッチ名>/` にも同じ `motor_driver.h` を置いてある。

**このファイルが正本。** 変更したら、次のコマンドで全サンプルに配りなおすこと。

```bash
cd v2
for f in */sample/*/motor_driver.h; do cp common/motor_driver.h "$f"; done
```

配り忘れがないかは次で確認できる（何も出なければ一致している）。

```bash
cd v2
for f in */sample/*/motor_driver.h; do diff -q common/motor_driver.h "$f"; done
```

## 右モーターPWM（ENA）のピン

| レッスン | ENA | 理由 |
|---|:--:|---|
| 11・12・13・15・16・17・18・19 | **D3** | D9 はサーボモーター用に空けておく（17で使う） |
| **14・20・21** | **D9** | IRremote が Timer2 を使い、D3 の `analogWrite` と両立しないため |

赤外線を使う3レッスンでは、スケッチの先頭で `#define USE_IR_ROBOT` を書くと
`motor_driver.h` が ENA を D9 に切りかえる。
