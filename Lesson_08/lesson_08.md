### ブザーをロボットに取り付けよう

ブザーをロボットのArduinoに直接つないで、**ロボットが動くたびに音で知らせる**ようにしよう。

#### 配線

| ブザーのピン | Arduinoのピン |
|---|---|
| VCC（＋） | 5V |
| GND（－） | GND |
| I/O（SIG） | D13 |

> **ポイント**：このレッスン以降のロボットレッスンでは、**ブザーをずっと搭載したまま使い続ける**よ。毎回 D13 に接続しておこう。

---

### 音デバッグとは？

プログラムを書いたとき「ロボットが本当にここを通ったのか？」「正しいルートを選んだのか？」を確かめたいことがあるよね。

ロボットはしゃべれないけれど、**ブザーで音を鳴らすことで「今何をしているか」を教えてくれる**ようにできる。これを**音デバッグ**という。

- 前進中：ピッ（短音）
- 後退中：ブー（長音）
- 右折：ピッピッ（2回）
- 左折：ピッピッピッ（3回）

目で見えないところを走っていても、音で「ちゃんと左に曲がったな」とわかるようになるよ！

### ミッションチャレンジ

#### サンプルコードを動かそう

```C++
#include "motor_driver.h"  // 標準モーター制御ライブラリ

#define BUZZ_PIN 13  // ブザー → D13

// ---- ブザー音パターン ----

// 短く1回（前進合図）
void buzz_short() {
  digitalWrite(BUZZ_PIN, LOW);
  delay(100);
  digitalWrite(BUZZ_PIN, HIGH);
}

// 長く1回（後退合図）
void buzz_long() {
  digitalWrite(BUZZ_PIN, LOW);
  delay(400);
  digitalWrite(BUZZ_PIN, HIGH);
}

// 2回（右折合図）
void buzz_twice() {
  buzz_short(); delay(100);
  buzz_short();
}

// 3回（左折合図）
void buzz_triple() {
  buzz_short(); delay(100);
  buzz_short(); delay(100);
  buzz_short();
}

// ---- 音付き移動関数 ----

void move_forward(int speed = 200, int time = 0) {
  buzz_short();          // 前進：短く1回
  go_Advance(speed, time);
}

void move_back(int speed = 200, int time = 0) {
  buzz_long();           // 後退：長く1回
  go_Back(speed, time);
}

void turn_right(int speed = 200, int time = 0) {
  buzz_twice();          // 右折：2回
  go_Right(speed, time);
}

void turn_left(int speed = 200, int time = 0) {
  buzz_triple();         // 左折：3回
  go_Left(speed, time);
}

// ---- setup / loop ----

void setup() {
  init_GPIO();
  pinMode(BUZZ_PIN, OUTPUT);
  digitalWrite(BUZZ_PIN, HIGH);  // 起動時はブザーOFF

  // 動作テスト：各方向に動きながら音で確認しよう
  move_forward(200, 1000);   // 前進 1秒
  move_back(200, 1000);      // 後退 1秒
  turn_right(200, 500);      // 右旋回 0.5秒
  turn_left(200, 500);       // 左旋回 0.5秒
  stop_Stop();
}

void loop() {
}
```

- [ ] ブザーが鳴りながらロボットが動いたらチェック！
- [ ] 前進・後退・右折・左折それぞれ違う音になっているかチェック！

#### 音パターンを自分でアレンジしよう

`buzz_short()` や `delay()` の時間を変えて、自分だけのオリジナル音パターンを作ってみよう。

> **ヒント**：`delay(100)` の数字を変えると音の長さが変わる。大きくすると長く、小さくすると短くなるよ。

- [ ] オリジナルの音パターンが作れたらチェック！

### まとめ

- **音デバッグ** ：ブザーの音でプログラムの動作を確認する手法
- `digitalWrite(BUZZ_PIN, LOW)` ：ブザーを鳴らす（アクティブブザー）
- `digitalWrite(BUZZ_PIN, HIGH)` ：ブザーを止める
- `delay(時間)` ：ミリ秒単位で待機する（音の長さを決める）
